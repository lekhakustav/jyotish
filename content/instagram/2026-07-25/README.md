# Instagram carousel package — 2026-07-25

Prepared from the delivery instructions and comments on GitHub issues #1, #2 and #3.

This is a social-media export package, not a change to the Jyotish app source. Daily and weekly Rashifal use the app's own brand system: Fraunces and Inter fonts, the exact warm cream canvas, sindoor-red titles, normal app subtitles, subtle temple-gold dividers and the Jyotish logo. The layout uses extreme minimalism: no content cards, shadows, gradients or decorative background panels.

Each Rashifal package is one 14-slide portrait carousel:

- `daily/01.png`–`14.png`: one English hook, 12 individual English zodiac readings in order and one final Jyotish app action page.
- `weekly/01.png`–`14.png`: the same structure for the weekly edition.
- Pisces is alone on slide 13; the Jyotish app promotion is alone on slide 14.
- `temples/` contains three temple visuals for a separate three-slide post.

Every sign has a specific decimal rating plus four cues: love, work, energy and a lucky cue. Editable SVG sources are in `design-source/`; copied app-brand fonts and logo are in `brand/`; English captions and disclosure text are in `captions.md`.

Upload the 14-slide version directly from an Instagram mobile app/account that offers the expanded carousel limit. Some accounts, desktop upload screens or third-party scheduling tools may still stop at 10.
