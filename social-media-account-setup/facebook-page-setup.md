## About section

Jyotish Baje is a Nepali astrology app designed to make daily Rashifal, Panchang, Kundali, Vastu and Jyotish information simple and easy to understand. The app supports Nepali and English and is created especially for users who prefer a clear and easy-to-use astrology experience.

## Manual steps

1. Create a Facebook Page named `Jyotish Baje`.
2. Select `Astrologer` or the closest available category.
3. Claim the first available username from the order above.
4. Add the display name, Intro, About text, email and Nepal as the location.
5. Leave the website empty if the official link is not ready.
6. Add the profile picture and cover photo.
7. Add the Learn More button and link it only when the official link is ready.
8. Review Page roles and keep only trusted admins.
