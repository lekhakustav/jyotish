# Security checklist

Complete this checklist manually after creating the accounts.

## Registration and recovery

- [ ] Register the accounts manually using `lekhakutsav@gmail.com`.
- [ ] Verify the email address on each platform.
- [ ] Use a strong, unique password for every account.
- [ ] Confirm the recovery email and phone number manually.
- [ ] Enable login alerts.

## Two-factor protection

- [ ] Enable two-factor authentication on Facebook, Instagram and TikTok where available.
- [ ] Save backup codes somewhere secure outside this project.
- [ ] Never share a password, OTP, recovery code or two-factor code with anyone.
- [ ] Do not save private login secrets in these Markdown files.

## Access review

- [ ] Review Facebook Page roles and admin access.
- [ ] Keep only trusted admins.
- [ ] Review connected Instagram and Meta Business Suite accounts.
- [ ] Remove unknown devices, sessions or connected apps.
- [ ] Confirm that messages from Facebook and Instagram are visible in Meta Business Suite.

## Final safety check

- [ ] The same approved profile picture, name and contact email are used across platforms.
- [ ] The website field is empty until the official Jyotish Baje link is ready.
- [ ] No fake website, password, OTP, recovery code or private login detail has been added.
